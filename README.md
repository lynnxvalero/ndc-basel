# New Dance Center Basel

Dieses Projekt zeigt eine Vorschau für das New Dance Center Basel: ein urbanes Tanzstudio mit Showgruppen, Workshops und flexiblen Kursen.

## Enthaltene Dateien

- `index.html` — NDC Basel Startseite und Inhalte
- `styles/style.css` — modernes Layout mit Animationen
- `scripts/main.js` — mobile Navigation und Reveal-Effekte

## So verwenden Sie es

1. Öffnen Sie `index.html` in Ihrem Browser, um die Seite lokal anzusehen.
2. Passe Texte, Bilder und Links in `index.html` an.
3. Ersetze den Stundenplan-Link durch deinen eigenen Inhalt, falls gewünscht.

## Hinweise

- Das Formular ist lokal und sendet keine echte Nachricht.
- Verwende dieses Gerüst als Basis für eine Agentur- oder Studio-Website mit NDC-Branding.
